AEGISCRYPT - QUICK START
=======================

Windows / VS Code terminal:

1. Create the environment
   python -m venv .venv

2. Activate it
   .\.venv\Scripts\Activate.ps1

3. Install dependencies
   pip install -r requirements.txt

4. Start the desktop application
   python desktop.py

CLI version check:
   python main.py --version

Expected:
   AegisCrypt 0.9.2

Live Server can be used to preview ui/index.html, but cryptographic actions require the desktop application because the browser preview does not have access to the Python engine.
