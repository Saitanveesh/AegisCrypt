AEGISCRYPT 7.0.0
================

Windows / VS Code terminal

1. Create the environment
   python -m venv .venv

2. Activate it
   .\.venv\Scripts\Activate.ps1

3. Install dependencies
   pip install -r requirements.txt

4. Start the desktop application
   python desktop.py

Version check
   python main.py --version

Expected
   AegisCrypt 7.0.0

New in version 7
- X25519 + Ed25519 identities
- optional sender-signed capsules
- local contact trust states
- Security Receipt v2
- expanded Attack Lab
- version-4 capsule compatibility

Live Server can preview ui/index.html, but cryptographic actions require the desktop application because the browser preview cannot call the local Python engine.
